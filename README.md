# ICC-MY–smooth muscle coupling: simulation code

Code and analysis scripts for

> Youm JB. *Muscle resting changes reach the intestinal pacemaker more than a pacemaker-cell model predicts: a test against drug and
> input-resistance data.* (submitted to The Korean Journal of Physiology & Pharmacology)

The model couples one myenteric interstitial cell of Cajal (ICC-MY) through a junctional conductance g_c to a column of circular smooth
muscle cells (SMC) with fibroblast-like cells (FLC, PDGFRα⁺ cells). It is used to test whether a published ICC model predicts the
resting-potential changes recorded in ICC-MY when drugs change the resting potential of the mouse small-intestinal muscle, and to compare
the model with the input resistance of freshly prepared ICC.

## Contents

| Path | What it is |
|---|---|
| `src/` | C++17 simulator `gisim` (`main.cpp`: all simulation modes and keys, documented in its header comments) |
| `src/ICC.*` | store-based ICC model of mouse small intestine (Youm et al. 2006, 2019), with switches for the changes made in this study |
| `src/SmoothM.*` | small-intestinal SMC model (equations and parameters in Supplement S1 of the paper) |
| `src/pdgfra/` | cell model used for the FLC (ICC-derived cell without ANO1, L-type and VDDR, with SK3; changes in Supplement S2) |
| `src/PohSMC.h` | human jejunal SMC model of Poh et al. 2012 (PLoS One 7:e42385), generated from the CellML repository version by `paper_R1/gen_poh_cpp.py`; used only as a check |
| `build.bat` | build with MSVC 2022 (OpenMP) and Eigen 3 |
| `run_v4win.ps1`, `run_v4ijp.ps1`, `paper_R1/run_paper_*.ps1`, `paper_R1/*.sh` | simulation batches for the calibration and robustness analyses |
| `paper_R1/*.py` | simulations (`run`), analyses (`analyze`) and figures; each script's header states its use and output |
| `paper_R1/*.out.txt` | text output of every analysis, as used for the paper |
| `paper_R1/kito_data.md` | literature data used for the tests (Supplement S9) |
| `paper_R1/planA/make_supp_tables.py`, `make_supp_S10.py` | supplementary tables (output `supp_tables_D.md`, `supp_S10_D.md`) |
| `paper_R1/fig/` | the figures of the paper (`D_fig1–6`, `A_figS1–S8`) as produced by the scripts |

Raw simulation output (`out/`, about 11 GB) is not included; it is regenerated by the `run` steps. See `REPRODUCE.md` for the order of
the steps and for where each figure, table and number of the paper comes from.

## Requirements

- Windows 10/11, Visual Studio 2022 (C++ build tools, OpenMP), Eigen 3.2 (header-only; `build.bat` expects it in `C:\eigen`).
- Python 3.11 with the packages in `requirements.txt`.
- The scripts call `bin/gisim.exe` and are run from the repository root, for example `python paper_R1/final_model.py run`.
